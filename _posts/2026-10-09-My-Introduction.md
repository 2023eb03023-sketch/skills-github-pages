I just published my first website using GitHub Pages, and it was easier than I expected.

## What I did

I created a repository, turned on GitHub Pages in the settings, and picked a theme. Then I added this blog post as a Markdown file in the `_posts` folder. A minute or two later, it was live on the web.

## What I liked

- No server setup or hosting fees
- Everything is stored in a repository, so I can see my changes over time
- Writing in Markdown is simple and quick

## What's next

I plan to customize my theme, add an About page, and write more posts as I keep learning.

Thanks for reading!
